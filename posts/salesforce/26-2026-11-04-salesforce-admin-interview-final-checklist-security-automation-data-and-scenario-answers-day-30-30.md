## The 4 Building Blocks

| Block | What it is | Key point |
| --- | --- | --- |
| **Security** | OWD, roles, sharing | Open up access |
| **Automation** | Flow and approvals | Lightest tool |
| **Data** | Import, clean, back up | Prevent first |
| **Delivery** | Sandbox to production | Test first |

---

## Interview Q&A

### 1. Where do you start on access?

Start with **OWD**, then open up with roles, sharing rules and permission sets.

> **Tip:** Open up, never lock down.

### 2. Flow or validation rule?

**Validation blocks bad data.** Flow automates the actions.

> **Tip:** Use the lightest tool.

### 3. How do you ship changes?

Build in a **sandbox**, then deploy with change sets.

> **Tip:** Test before production.

### 4. How do you keep data clean?

Use **duplicate rules**, restricted picklists and validation rules.

> **Tip:** Prevent first, then clean.

### 5. How do you protect data?

Schedule **data exports** and know what the Recycle Bin keeps.

> **Tip:** Back up before big changes.

### 6. How do you answer scenarios?

**State the goal, name the tool, give the steps, mention a test.**

> **Tip:** Keep it under a minute.

## Scenario Question

**"A new sales team joins. What do you set up?"**

1. **Add** roles and permission sets
2. **Set** record types and layouts
3. **Build** flows and validations
4. **Test** in a sandbox first

## Quick Cheat Sheet

- **Access** = OWD first
- **Rules** = validation blocks
- **Automation** = Flow
- **Release** = sandbox first
- **Data** = prevent duplicates
- **Answer** = goal, tool, steps

## Key Takeaways

- Start with the goal
- Use the lightest tool
- Test before production
- Explain it in four steps
