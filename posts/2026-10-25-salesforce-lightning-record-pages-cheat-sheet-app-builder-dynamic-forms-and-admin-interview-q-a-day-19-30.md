## The 4 Building Blocks

| Block | What it is | Key point |
| --- | --- | --- |
| **App Builder** | Drag and drop page tool | Clicks, not code |
| **Page Types** | App, home, record | Pick the right one |
| **Components** | Standard or custom blocks | Drop onto the page |
| **Activation** | Org, app or profile | Assign to take effect |

## Interview Q&A

### 1. What is Lightning App Builder?

A **drag and drop tool** to build app, home and record pages without code.

> **Tip:** Clicks before code.

### 2. What are the page types?

**App pages, home pages and record pages**, each for a different job.

> **Tip:** Record pages show one record.

### 3. What are components?

**Building blocks** like the Highlights Panel and Related Lists you drop on a page.

> **Tip:** Keep pages light and fast.

### 4. What are Dynamic Forms?

They **show or hide fields by rules** instead of one fixed layout.

> **Tip:** They can replace extra layouts.

### 5. What is component visibility?

A **filter that shows a component only when conditions are met**, like profile or field value.

> **Tip:** Less clutter for each user.

### 6. How do you activate a page?

Assign it as **org default, app default, or by app, record type and profile**.

> **Tip:** The most specific one wins.

## Scenario Question

**"Reps need a cleaner Opportunity page. How?"**

1. **Clone** the standard record page
2. **Add** components and set visibility
3. **Use** Dynamic Forms for key fields
4. **Activate** for the sales app

## Quick Cheat Sheet

- **App Builder** = page tool
- **Record page** = one record
- **Dynamic Forms** = field rules
- **Visibility** = show if
- **Clone** = safe start
- **Activation** = who sees it

## Key Takeaways

- Clone, never edit the standard page
- Hide what users do not need
- Fewer components load faster
- Test as the user profile
